# تعريب Valheim | Valheim Arabic

<div dir="rtl">

تعريب كامل لـ Valheim (نسخة ستيم 1.0.20): القوائم والأدوات والبناء والمهام والحوارات والنصائح والحكايات والألقاب، وترجمة مقدمة ونهاية اللعبة. العربية تنضاف كلغة جديدة، والإنجليزية وباقي اللغات تبقى مثل ما هي.

التعريب ما يحتوي أي ملف من ملفات اللعبة. البرنامج يعدّل ملفات اللعبة اللي عندك أنت ويحفظ نسخة من الأصلية.

## اللي تحتاجه

1. نسخة ستيم من Valheim، **الإصدار 1.0.20** (رقم البناء 25909357).
2. حوالي 2 جيجا مساحة فاضية (نسخة احتياطية من الملفات الأصلية).

## الخطوات

1. سكّر اللعبة.
2. حمّل `Valheim-Arabic-1.0.zip` من [Releases](../../releases/latest) وفك ضغطه.
3. افتح `ValheimArabic.exe`. إذا طلعت رسالة "Windows protected your PC" اضغط More info ثم Run anyway (البرنامج مو موقّع رقميًا).
4. اختر مجلد اللعبة (`steamapps\common\Valheim`، البرنامج يلقاه بنفسه غالبًا) واضغط «ثبّت التعريب».
5. شغّل اللعبة: Settings ← Gameplay ← Language ← **العربية**.

## الإزالة
افتح `ValheimArabic.exe` واضغط «أزل التعريب». ترجع ملفاتك الأصلية من النسخة الاحتياطية.

## ملاحظات
- إذا حدّثت ستيم اللعبة، ملفات التعريب ترجع إنجليزي. ثبّت إصدار التعريب اللي يناسب التحديث.
- باقي بالإنجليزي: أسماء الطاقم، أزرار يد التحكم، وثماني رسائل قليلة مكتوبة داخل كود اللعبة (رسالة الإصلاح، أخطاء تحميل العالم، تغيير تخطيط يد التحكم، كلمة "الإصدار" في القائمة، تلميح حجر البوابة).
- الخط: Noto Naskh Arabic (رخصة SIL Open Font License 1.1).
- كود البرنامج موجود في مجلد [`app`](app) في هذي الصفحة، وتقدر تبنيه بنفسك بـ `build.cmd`.

## English

Complete Arabic translation of Valheim (Steam version 1.0.20): menus, items, building, quests, dialogue, tips, lore,
titles, the intro and ending subtitles. Arabic is added as a new language;
English and the other languages stay as they are.

No game file is included. The program patches the game files of your own copy and keeps a backup of the originals.

### What you need

1. The Steam version of Valheim, **version 1.0.20** (build 25909357).
2. About 2 GB free (backup of the original files).

### Steps

1. Close the game.
2. Download `Valheim-Arabic-1.0.zip` from [Releases](../../releases/latest) and extract it.
3. Open `ValheimArabic.exe`. If "Windows protected your PC" appears, click More info, then Run anyway (the program is
   not digitally signed).
4. Choose the game folder (`steamapps\common\Valheim`; the program usually finds it) and click "Install".
5. Start the game: Settings > Gameplay > Language > **العربية**.

### Uninstall
Open `ValheimArabic.exe` and click "Uninstall". Your original files come back from the backup.

### Notes
- If Steam updates the game, its files go back to English. Install the translation version made for that update.
- Still in English: crew names, controller button names, and eight short messages written in the game's code (repair
  message, world load errors, controller layout change, the word "Version" in the menu, waystone hint).
- Font: Noto Naskh Arabic (SIL Open Font License 1.1).
- The program's source is in the [`app`](app) folder of this page; build it yourself with `build.cmd`.
